🔐 Установка сертификата

Корневой сертификат (CA) этого сервера — чтобы подключиться к нему безопасно и по всем адресам сети.

Зачем это нужно?
Стек использует собственный (локальный) центр сертификации для HTTPS. Браузеры блокируют доступ к микрофону и динамикам на сайтах, чей сертификат не вызывает доверия. Поэтому без установки этого сертификата голосовой ввод (STT) и озвучка (TTS) работать не будут — даже если страница открывается по https. Установив сертификат один раз, вы разрешаете работу микрофона и динамиков на любом адресе этого сервера.
Важно: устанавливайте сертификат именно в браузер.
Яндекс Браузер и Chrome используют собственное хранилище доверенных сертификатов, а не системное. Поэтому одной установки ca.crt в систему (через update-ca-certificates на Linux) недостаточно — сайт всё равно будет показывать «Не защищено», и микрофон останется заблокированным. Способ через browser://certificate-manager/ ниже — основной и самый надёжный.
{% if cert_available %} ⬇ Скачать сертификат (ca.crt) {% else %} Сертификат ещё не готов — повторите позже {% endif %}

Установка: Windows (Яндекс Браузер / Chrome / Edge)

Основной способ — импорт в браузер:
1. Скачайте ca.crt кнопкой выше.
2. В адресной строке браузера откройте browser://certificate-manager/ (в Chrome — chrome://certificate-manager).
3. Перейдите в раздел «Персонализированные» → «Доверенные сертификаты» → нажмите «Импорт» → выберите скачанный ca.crt.
4. Подтвердите, что это корневой центр, и закончите импорт.
5. Полностью закройте браузер и откройте заново → откройте сайт — щит должен стать не перечёркнутым («Защищено»).
Альтернатива (системное хранилище Windows):
1. Нажмите Win + R, введите certmgr.msc и нажмите Enter.
2. В дереве слева разверните Доверенные корневые центры сертификации → правый клик по Сертификаты → Все задачи → Импорт.
3. Далее → Обзор → выберите ca.crt → Далее → «Поместить все сертификаты в следующее хранилище» → Обзор → Доверенные корневые центры сертификации → ОК → Готово → Да.
4. Полностью перезапустите браузер.

Установка: Linux (Яндекс Браузер / Chrome)

Основной способ — импорт в браузер (иначе «Не защищено»):
1. Скачайте ca.crt кнопкой выше.
2. В адресной строке откройте browser://certificate-manager/ (в Chrome — chrome://certificate-manager).
3. Раздел «Персонализированные» → «Доверенные сертификаты» → «Импорт» → выберите ca.crt → подтвердите, что это корневой центр.
4. Полностью перезапустите браузер → откройте сайт — щит должен стать не перечёркнутым, микрофон станет доступен.
Альтернатива — системное хранилище (для системных приложений: curl, openssl):
sudo cp ca.crt /usr/local/share/ca-certificates/selfhosted-ai-ca.crt
sudo update-ca-certificates
Затем полностью перезапустите браузер. Внимание: одного этого системного способа для Яндекс/Chrome может быть недостаточно — предпочтите способ выше.

Установка: Android

1. Скачайте ca.crt на устройство.
2. Настройки → Безопасность → Ещё настройки безопасности → Установка сертификатов → Сертификат CA → выберите файл.
3. Перезапустите браузер.

После установки

1. Полностью перезапустите браузер и откройте сайт по https (например https://192.168.162.119/) — щит должен стать не перечёркнутым («Защищено»).
2. Разрешите микрофон: кликните на значок у адресной строки → раздел «Микрофон» → «Разрешить» (или через browser://settings/content/microphone, в Chrome — chrome://settings/content/microphone).
3. Обновите страницу — голосовой ввод (STT) и озвучка (TTS) заработают.
На Linux озвучка (TTS) не работает в Chrome/Яндекс?
Это известное ограничение Chromium на Linux — Web Speech API не интегрирована с системным TTS. Используйте Firefox — он работает сpeech-dispatcher/RHVoice из коробки. Chrome/Яндекс на Windows/macOS озвучивают без проблем.
Щит не перечёркнут, но микрофон всё равно «отказано»?
Значит сертификат уже доверенный, а блокирует именно разрешение на микрофон в самом браузере (сайта может не быть ни в «Разрешено», ни в «Запрещено» — тогда браузер просто ещё не спрашивал). Откройте страницу по https (не прямой http://…:8081 — на http браузер запрещает микрофон в принципе), нажмите значок у адресной строки → «Микрофон» → «Разрешить», затем перезагрузите страницу (F5). Если запроса на микрофон нет — проверьте, что микрофон доступен в системе (не занят другим приложением и виден браузеру).

Сертификат создаётся автоматически и покрывает localhost и все внешние сетевые адреса сервера. При перезапуске сервиса обновлять его на устройствах снова не нужно — достаточно установить один раз. Скачивайте ca.crt именно кнопкой выше, чтобы получить свежую версию CA.
